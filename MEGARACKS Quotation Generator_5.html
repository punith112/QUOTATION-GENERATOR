How to use this tool

Everything you need to raise, save and send a quotation.
Raising a quotation, start to finish
Fill in the customer details and pick your name under Sales engineer. Browse a rack size tab or use the search box, set the quantity, and press + to add each item. Check the summary on the right, then press Generate quotation.
Finding a product quickly
Type into the search box at the top — it looks across every category at once, so "42U glass door" or "shoe rack" gets you there in one step. Each result shows which category it came from.
Changing a price for one customer
In the summary, type over the figure in the Rate box. This changes the price for this quotation only; the catalogue keeps its original rate.
How the discount column works
Enter a percentage in the Disc % box. The customer never sees it — the printed quotation, PDF and email all show the reduced unit price as if it were the standard rate. The discount is recorded in your Google Sheet for internal reference.
Editing a description
Descriptions are editable in two places.

In the product list — tap the name and type to change it permanently for this device. The item is marked EDITED; clear the text completely to restore the original wording.

In the quotation summary — tap the name to change it for this quotation only, leaving the catalogue untouched. Useful for one-off notes like "powder coated RAL7035 as per site".

Press Enter or tap elsewhere when done.
Reordering the items
Drag the handle at the left of any row, or use the small arrows next to it. The order you set is the order that appears on the quotation.
Quoting something not in the catalogue
Add one-off item is for this quotation only — installation charges, transport, a special fabricated part.

Add new product to catalogue saves it permanently under a category of your choice, so it is there next time. Back these up with the Back up products button.
Sending it to the customer
Print / Save PDF for a clean copy.
Send PDF on WhatsApp makes the PDF and opens the share sheet — on a phone it attaches the file directly.
Send by Email downloads the PDF and opens your mail app with the message written; attach the file and send.
Save as Excel if the customer wants the figures in a spreadsheet.
Saving and reopening quotations
Once cloud sync is set up, press Save to Sheet on any generated quotation. Open Saved quotations to search past ones and reopen them with all items intact — ideal for repeat orders and revisions.
Tracking leads and follow-ups
Switch to the Leads & follow-up tab at the top. Press + Add lead after a cold call and record the company, contact, where it came from, the value you expect and when to call back.

Stage sets the chance of closing automatically — New 10%, Contacted 25%, Quoted 50%, Negotiation 75% — and you can drag the slider to your own figure. Anything from 60% up is High, 30 to 59 is Medium, below 30 is Low.

The cards sort by follow-up date, so whoever is overdue sits at the top in red. Each card has quick buttons to call, send a WhatsApp follow-up, start a quotation with the details filled in, move to the next stage, or push the callback out a week.

Generate a quotation for a company already on the list and the lead updates itself — the reference is attached, the value set to the quoted total, and the stage moved to Quoted.
Turning a quotation into a proforma invoice
On any generated quotation press → Convert to Proforma. Give it a proforma number (one is suggested) and the customer P.O. number if you have it.

The proforma carries the same items and totals plus the amount in words, full bank details, and the SBI UPI QR code for scan-and-pay. An order record is created at the same time, so it appears under Orders & status straight away.
Tracking an order through production
The Orders & status tab holds everything after the quotation: P.O. number and date, proforma number, payment terms, order value, advance received and balance due, expected dispatch date, and transport or LR details.

Status moves through Proforma sent → PO received → Advance received → In production → Ready to dispatch → Dispatched → Delivered → Payment pending → Closed. Use Next status to step it along.

There are two separate remark boxes — Customer remarks in blue for site readiness or delivery instructions, and Production remarks in amber for material status and fabrication hold-ups — so sales and works notes never get mixed up.
What the pipeline figures mean
Pipeline is the total value of every open lead. Weighted multiplies each by its chance of closing, which is the more realistic number to plan against. Conversion is won as a share of everything closed, so it only counts leads you have marked Won or Lost.
Managing sales engineers
Press Manage beside the Sales engineer box to add or remove names with their mobile and email. The selected engineer appears as the contact on the quotation.
Nothing saved — where did my work go?
The cart and customer details save automatically in this browser, so closing the tab is safe. They are cleared if you clear browsing data or switch device — use Save to Sheet for anything you need to keep.
Connecting everyone to the sheet at once
By default each person pastes the Web app URL into Cloud settings on their own device. To avoid that, open this HTML file in a text editor, find var DEFAULT_CLOUD_URL = ''; near the top of the script, paste your URL between the quotes, and re-upload the file. Everyone who opens it is then connected automatically, with auto-save on.

Anyone can still override it on their own device from Cloud settings, and switch back with the link in that screen.

Bear in mind that the URL is readable in the page source, so anyone who can open the page can read and write that sheet. Keep the repository private if that matters.
Clip, the assistant — hiding and bringing him back
Clip sits in the bottom-right corner. He greets whoever is set as sales engineer, flags overdue follow-ups and uninvoiced dispatches, and runs a lap of the screen when you win an order or dispatch one.

Quiet please keeps him on screen but silent until you tap him. This is remembered.
Hide for now (or the small × on his shoulder) removes him completely. He returns when you reload the page, or immediately via Bring back Clip in the menu under Settings.
Changing the passcode
Press Passcode in the top bar, enter the current code and the new one twice. Leave Apply to all devices ticked and the new code is stored in your Google Sheet, so every engineer picks it up automatically. Untick it to change the code on this device only.

If you are locked out completely, open the Settings tab of the sheet to read the current code, or clear the site data in your browser to fall back to the code built into the file.
